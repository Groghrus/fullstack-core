# Документация проекта fullstack-core

Здесь хранится документация проекта

## Содержимое

- `THEME-GUIDE.md` — формат и структура каждой темы (frontmatter, секции, quiz).
- `README.md` — этот файл.

## Как добавлять темы

1. Внести тему в блок в `../packages/content/registry.json` (если ещё нет).
2. Создать файл `../packages/content/themes/<block>/<theme>.md` по шаблону из `THEME-GUIDE.md`.
3. Наполнить по формату C (все секции + quiz + источники).
4. Обновить статус в `related`-полях соседних тем и в рабочем `TASKS.md` (вне репо).

## Договорённости

- Контент на русском, термины EN + перевод в скобках.
- Примеры кода: TypeScript → Go → Java.
- Диаграммы: mermaid.
- Quiz: draft-вопросы генерируются агентом и правятся вручную.
