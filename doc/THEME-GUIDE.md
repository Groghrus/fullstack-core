# Как устроена каждая тема

Каждая тема — отдельный Markdown-файл в `packages/content/themes/<блок>/<тема>.md`.

## Frontmatter (YAML)

```yaml
---
id: rate-limiting            # латиницей, kebab-case
title: Rate Limiting (Ограничение количества запросов)
block: 08-nadezhnost-resilience   # id блока из packages/content/registry.json
tags: [rate-limiting, resilience, api, networks]
order: 1                      # порядок внутри блока
related:                      # связи с другими темами (вручную)
  - retries
  - circuit-breakers
  - api-gateway
  - backpressure
difficulty: medium            # beginner | medium | advanced
languages: [typescript, go, java]
status: done                  # draft | done
---
```

## Секции (внутри тела файла)

1. **Определение** — что это, RU + EN термин, 1–2 предложения
2. **Зачем нужно** — какие проблемы решает
3. **Как работает** — принцип, ключевые понятия
4. **Диаграммы** — mermaid (`sequenceDiagram`, `graph`, `flowchart`)
5. **Примеры кода** — в порядке TypeScript → Go → Java
6. **Пример использования: интеграция** — как встроить в реальное приложение (middleware/Interceptor на TS/Go/Java)
7. **Паттерны использования** — best practices
8. **Антипаттерны и ловушки** — чего избегать
9. **Когда использовать / когда НЕ использовать**
10. **Связанные темы** — перечень с краткими пояснениями
11. **Вопросы (quiz)** — секция со списком вопросов
12. **Источники** — официальная документация, адаптированная на русский

## Условные обозначения

- Термины: на английском + перевод в скобках, напр. `Rate Limiting (Ограничение количества запросов)`
- Код: примеры на **TypeScript → Go → Java** в указанном порядке
- Диаграммы: только mermaid (текстовый формат, рендерится приложением)

## Статус темы

- `draft` — черновик, контента мало/нет
- `done` — расписана полностью по всем секциям

## Quiz

Секция `## Вопросы` — список объектов. Каждый вопрос имеет формулировку, варианты ответов, порядковый номер правильного варианта и пояснение. Draft-вопросы генерируются автоматически при написании темы, затем правится вручную.
